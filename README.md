# English B2 Path

Курс английского **с нуля до B2** по плану «План обучения английскому: с нуля до B2» (18 месяцев × 7 часов в неделю ≈ 550 часов). Приложение ведёт за руку: каждый день открываете **«Сегодня»** и делаете то, что там написано.

## Что внутри

| Раздел | Что делает | Откуда в плане |
|---|---|---|
| 📅 Сегодня | Задачи учебного дня по недельной структуре плана: Пн/Ср/Пт — урок + Anki + слушание, Вт — говорение + разбор ошибок, Чт — письмо + повтор диалогов, Сб — свободное слушание/чтение + свои фразы, Вс — Anki + обзор недели | «Недельная структура и правила» |
| 🗺️ Карта курса | 4 фазы, 78 недель, контрольные точки (месяцы 3, 6, 12, 18) | Фазы 1–4 |
| 📘 Уроки | 106 уроков: фонетика (неделя 1), A1 — 24, A2 — 24, B1 — 27, B2 — 27. Подробные объяснения по-русски, озвучка каждого примера, упражнения с разбором ошибок, мини-повтор в начале урока | «Основной курс» каждой фазы |
| 🃏 Слова | Встроенный Anki (SM-2): колоды «Основа» и «Мои фразы», лимит 10/12/15 новых в день, тематические наборы, генерация фраз ИИ | «Слова только во фразах» |
| 🎧 Слушание | Диалоги уроков и библиотека: 3 прослушивания + shadowing, вопросы на понимание | «Слушание» |
| 📖 Чтение | Тексты A1–B2 с глоссарием и вопросами, генератор текста на интересную тему | «Чтение» |
| 🗣️ Говорение | ИИ-партнёр по темам фаз (исправляет ошибки и объясняет), голосовой ввод, ежемесячная запись голоса | «Говорение», «Контроль прогресса» |
| ✍️ Письмо | Задания фаз, проверка ИИ с объяснением каждой ошибки | «Письмо» |
| 💼 Рабочий английский | 12 сценариев с 7–12 шаблонными фразами и ролевой игрой (с месяцев 5, 9, 13) | «Рабочая ветка» |
| 🐞 Мои ошибки | Все ошибки из уроков, письма и разговоров + упражнения по ним | «Ошибки записывайте» |
| 📊 Прогресс | Журнал: дата, минуты, блок, заметка; часы по блокам; путь A1→B2 по часам | «Удобный способ вести учёт» |

**ИИ-наставник** — кнопка «🤖 Непонятно — объясни подробнее» на каждом шаге урока и плавающая кнопка «Спросить наставника» на любом экране. Объясняет другими словами, с аналогиями с русским, примерами и мини-заданиями; разбирает конкретную ошибку ученика.

## Запуск

Сборка не нужна — это статический сайт на ES-модулях.

```bash
python -m http.server 5288
```

Откройте http://localhost:5288. Прогресс хранится в `localStorage` браузера; в настройках есть выгрузка/загрузка копии.

## Подключение ИИ-наставника

Работает так же, как в Terminal Ops Academy: сначала функция Supabase, при её отсутствии — личный ключ.

### Вариант 1. Личный бесплатный ключ (2 минуты, только для себя)

1. https://console.groq.com/keys → войти через Google → **Create API Key**.
2. В приложении: ⚙️ Настройки → ИИ-наставник → вставить ключ → «Проверить связь».

Ключ хранится только в этом браузере.

### Вариант 2. Функция Supabase `english-tutor` (для всех устройств, ключ на сервере)

Используется тот же проект Supabase, что у DevOps-игры (`eotzgzaeuzvreidwkltf`). Секрет `GROQ_API_KEY` в нём уже задан — он общий для всех функций проекта.

1. Supabase Dashboard → Edge Functions → **Deploy a new function** → **Via Editor**.
2. Имя: `english-tutor`. Вставьте содержимое `supabase/functions/english-tutor/index.ts`.
3. В настройках функции **выключите «Enforce JWT verification»** (страница статическая, вход не нужен; защита — белый список Origin и лимит запросов).
4. Если сайт будет жить не на `https://ruslan4212.github.io` или `localhost:5288`, добавьте секрет `ENGLISH_ALLOWED_ORIGINS` со списком адресов через запятую.

Или через CLI: `supabase functions deploy english-tutor --no-verify-jwt`.

Промпты живут в одном месте — `js/prompts.js`. После их правки пересоберите функцию:

```bash
python tools/build_function.py
```

## Честно о границах

Всё обучение — внутри приложения: учебник (уроки), репетитор (Мия, живой звонок), карточки, слушание, чтение, письмо и встроенный тест уровня. Ничего искать снаружи не нужно.
